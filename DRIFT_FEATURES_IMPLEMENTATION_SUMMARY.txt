STEP 2-3 — FORWARD DRIFT PREDICTION (NEW IMPLEMENTATION)
================================================================================

ADDED: LagrangianDriftEngine.run_forward_prediction()
LOCATION: backend/app/services/drift_engine.py (lines ~54-185)

FUNCTIONALITY:
✓ Seeds particles at observed spill polygon (t=0)
✓ Forward time integration: u_drift = +(u_current + f_wind * u_wind)
  - NO sign inversion (contrast with backward drift's negative sign)
✓ Same stochastic diffusion as backward drift
✓ Configurable projection window (default: 48 hours)
✓ Uncertainty grows with time horizon (reflects increasing prediction error)
  - Base uncertainty + 1.5% growth per hour
  - Diffusion coefficient scales with time: (1.0 + 0.015 * elapsed_hours)
✓ Returns: predicted centroid, ellipses, heatmap, trajectories

PARTICLE COUNT:
- Default: 300 particles (vs 1200 for backward drift)
- Rationale: Forward prediction is compute-intensive; 300 provides sufficient
  statistical coverage for prototype performance

FORCING DATA:
- Simplified constant current/wind vectors (same as backward drift)
- Documented via "forcing_data_source": "simplified_constant" in response
- Future extensibility: designed to accept live CMEMS + ERA5 feeds

UNCERTAINTY HANDLING:
✓ Uncertainty is NOT constant — grows with time horizon as expected
✓ Early timesteps (t+6h): ~1.6 km radius
✓ Late timesteps (t+48h): ~20-25 km radius
✓ Reflects fundamental physics: forecasts become less certain over time
