WHAT WAS IMPLEMENTED (NEW CODE)
================================================================================

1. FORWARD DRIFT PREDICTION
   File: backend/app/services/drift_engine.py
   Function: LagrangianDriftEngine.run_forward_prediction()
   
   Key differences from backward drift:
   - Positive time integration (no sign inversion)
   - Diffusion grows with time: (1.0 + 0.015 * elapsed_hours)
   - Uncertainty scales with time horizon (not constant)
   - Default 300 particles (vs 1200 backward) for performance
   
   Physics:
   - u_drift = +(u_current + 0.031 * u_wind)  [FORWARD]
   - vs backward: -(u_current + 0.031 * u_wind)
   
   Output includes:
   - Predicted centroid position at t + duration_hours
   - Uncertainty ellipses at timesteps
   - KDE heatmap for visualization
   - Sample trajectories (40 particles)
   - Forcing data source: "simplified_constant" (documented)

2. API ENDPOINTS
   File: backend/app/api/routes_drift.py
   
   NEW ENDPOINTS:
   
   GET /api/drift/{case_id}/forward-prediction
   - Query params: duration_hours (default: 48), num_particles (default: 300)
   - Returns forward drift prediction from current spill
   - Uncertainty grows with time horizon
   
   GET /api/drift/{case_id}/combined
   - Returns BOTH backward + forward in one call
   - Structure:
     {

       "spill_centroid_lon": ...,
       "backward_drift": { DriftOriginEstimate },
       "forward_prediction": { forward dict },
       "note": "..."
     }
